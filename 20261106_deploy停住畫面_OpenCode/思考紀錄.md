# 思考紀錄

## 1. 需求拆解

原本 `deploy.bat` 只是分派給 `aws/ops.py`，跑完立刻 `exit /b %ERRORLEVEL%`：

- 雙擊 `.bat` 時視窗秒閉，結果來不及看。
- `aws/deploy.py` 不論 rollout 有沒有 `COMPLETED`，都印 `=== 部署完成 ===`，
  失敗與成功看起來一樣。

所以要補兩件事：**顯示成功與否** + **跑完停住畫面**。

## 2. 六個核心觀點

1. **成功與否要用 exit code 表達，不能只用文字**：`aws/deploy.py` 現在 `raise SystemExit(0/1)`，
   `aws/ops.py`、`deploy.bat`（`%ERRORLEVEL%`）、`deploy.ps1`（`$LASTEXITCODE`）都能據此判斷。
2. **「部署完成」不等於「上線成功」**：rollout `COMPLETED` 只表示任務被換掉，
   真正成功還要 ALB 的 `/api/health` 打得通且 `ok=true`，所以新增第 6 步健康檢查（重試 3 次）。
3. **暫停要放在選單層（`aws/ops.py`），不要放在 deploy 腳本內**：
   `ops.py` 會用 subprocess 呼叫 `deploy.py`，兩邊都暫停就會按兩次鍵。
4. **自動化不能被暫停卡死**：`stdin.isatty()` 為 False（pipe、redirect、CI）時自動跳過暫停；
   另外提供 `--no-pause` 與 `LUCA_NO_PAUSE=1`。`deploy.ps1` 用 `[Console]::IsInputRedirected` 做同樣的事。
5. **結果寫進 state 檔**：新增 `lastDeployOk` / `lastDeployHealth`，之後 `python aws/status.py` 可以看到
   最後一次發佈的結論，不會只留在螢幕上。
6. **`deploy.bat` 維持全 ASCII、≤1024 bytes**：暫停與中文訊息都由 Python 負責，
   `.bat` 本身不動（目前 501 bytes），符合 cmd 的 1024-byte 塊限制。

## 3. 改動清單

| 檔案 | 改了什麼 | 原因 |
|---|---|---|
| `aws/deploy.py` | 輪詢結果存入 `ok`/`rollout`；新增健康檢查；印 `=== 發佈結果 ===`；`raise SystemExit(0/1)`；`import time`、`import urllib.request` 移到頂部 | 原本 `import time` 藏在 if 內、且結束必定印「部署完成」；改成可判定的結論 |
| `aws/ops.py` | 新增 `pause()`、把分派抽成 `dispatch()`、`main()` 結束印 `=== 結果：✔/✘ ===` 後暫停；支援 `--no-pause` | 選單是雙擊 .bat 的實際進入點，暫停放這裡最合理 |
| `deploy.ps1` | 新增 `-NoPause` 與 `Pause()`，switch 結束後暫停；`Deploy` 依 `$LASTEXITCODE` 印 `RESULT: SUCCESS/FAILED` | .ps1 被直接雙擊時也會秒閉；ASCII 註釋維持 PS 5.1 的 ANSI 讀取安全 |
| `readme.md` | 第 4 節補一段「跑完會印結果並停住」 | 文件與行為一致 |

保留原有註解與輸出格式，只有語意（「部署完成」→「發佈結果」）改成可驗證的結論。

## 4. 範例輸出

成功：

```
=== 5) wait for the rolling deployment ===
   1 [('COMPLETED', '12', 1, 1)]
=== 6) health check ===
  ✔ http://<ALB>/api/health -> 200 ok=True env=production

=== 發佈結果 ===
  ✔ 成功（rollout COMPLETED）
  task definition: luca-python:12
  image:           <ecr>:20261106041210
  health check:    ✔ 通過

=== 結果：✔ 成功 ===

按 Enter 結束（結果已在畫面上）...
```

失敗（超時或健康檢查不過）：

```
=== 發佈結果 ===
  ✘ 失敗（rollout TIMEOUT）
  health check:    ✘ 不通過
  看為什麼失敗：python aws/status.py --logs 20

=== 結果：✘ 失敗（exit 1） ===

按 Enter 結束（結果已在畫面上）...
```

## 5. 驗證方式

- `python -m py_compile aws/deploy.py aws/ops.py` → exit 0。
- `powershell -NoProfile -Command "[scriptblock]::Create((Get-Content deploy.ps1 -Raw))"` → parse ok。
- `python aws/ops.py nope` → 印 `✘ 失敗（exit 1）` 後進入暫停（stdin 非終端機時自動跳過）。
- `deploy.bat` 仍是 501 bytes，未超過 1024 bytes。
- 實際跑一次 `deploy.bat` 需在能連 AWS 的環境，本機只跑到語法與分派層驗證。

## 6. 可再改進的地方

1. 若希望雙擊 `.bat` 也能保留 **執行時間** 與 **完整輸出檔**，可把暫停前加一份 log（`Tee-Object`/Python 端寫 `deploy.log`）。
2. `aws/status.py` 目前不會讀 `lastDeployOk`；要的話可加一行顯示最後一次發佈結論。
3. 健康檢查目前是 HTTP（ALB 沒有 HTTPS listener），正式區若改 HTTPS 需要對應調整。
